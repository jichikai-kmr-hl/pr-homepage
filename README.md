# 旧 URL からの転送

このリポジトリはサイト本体ではありません。

`https://jichikai-kmr-hl.github.io/pr-homepage/` へのアクセスを、正規 URL `https://jichikai-kmr-hl.github.io/` へ飛ばすためだけに使います。

| 用途 | 場所 |
|------|------|
| サイト本体（修正・CSV 更新はこちら） | https://github.com/jichikai-kmr-hl/jichikai-kmr-hl.github.io |
| 公開サイト | https://jichikai-kmr-hl.github.io/ |

GitHub Pages は HTTP 301 を出せないため、各 HTML で meta refresh と JavaScript による即時転送にしています。
